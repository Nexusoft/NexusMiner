📋 Master Reference Card

RULE 1hashPrevBlock is the PRIMARY staleness anchor
template.block.hashPrevBlock != node.hashBestChain → stale, discard immediately (StakeMinter pattern)
RULE 2block.nHeight = UNIFIED blockchain height (tStateBest.nHeight + 1)
ProofHash() hashes nVersion→nBits range which includes nHeight at bytes [200-203]. NEVER overwrite with channel height.
RULE 3nChannelHeight is METADATA ONLY — for staleness detection, never in block bytes
HeightTracker::Snapshot::is_template_stale() = channel_height ≥ channel_target (single source of truth)
RULE 4ValidateTemplate() performs dual height check
template.nHeight == nNodeUnified + 1 AND template.nChannelHeight == nNodeChannel + 1
RULE 5Submission audit aborts if block.nHeight looks like channel height
prepare_block_submission(): if (nHeight < last_unified/2) → ABORT — nHeight was corrupted
RULE 6hashMerkleRoot MUST be rebuilt whenever producer is touched
After every UpdateProducerTimestamp() + Sign() call, rebuild merkle tree before submitting

📦 216-byte Tritium Block Serialization (Bytes in ProofHash range)

[  0-  3]  nVersion      (4 bytes)
[  4-131]  hashPrevBlock (128 bytes)  ← PRIMARY staleness anchor
[132-195]  hashMerkleRoot(64 bytes)   ← must be rebuilt after producer update
[196-199]  nChannel      (4 bytes)
[200-203]  nHeight       (4 bytes)   ← UNIFIED height (tStateBest.nHeight+1) — NEVER channel height!
[204-207]  nBits         (4 bytes)
[208-215]  nNonce        (8 bytes)
           Total: 216 bytes

ProofHash() for Prime = SK1024(BEGIN(nVersion), END(nBits))
                       = hashes bytes [0..207], which INCLUDES nHeight @ [200-203]
